📷 A22 Camera Link

iPadで映像・音声を受信するPWAです。映像と音声はWebRTCで端末間に送信し、GASには接続情報だけを一時保存します。

STUNだけで接続できないネットワークではTURNが必要です。TURNを使う場合は、利用契約のあるサーバー情報をここへ入力してください。認証情報はこのiPad内に保存し、GitHubには登録しません。

待機中

受信映像・音声

iPadの消音スイッチ・音量・Safariの自動再生制限により、最初に音声ボタンを押す必要がある場合があります。

接続手順

1. GASをデプロイしてURLを入力します。
2. 接続コードを作り、Androidアプリにも同じ12桁を入力します。
3. Androidで「配信開始」を押し、通知に「カメラ・マイク使用中」と表示された状態にします。
4. iPadで「接続して受信」を押します。
5. 画面をロックする場合も、Androidの配信通知を残してください。

このコードは個人利用向けの試作です。接続コードを他人に共有しないでください。Androidが停止・再起動された場合は、アプリを開いて配信を再開する必要があります。
